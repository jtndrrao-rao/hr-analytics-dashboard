# 📈 HR Analytics Dashboard — Talent Acquisition

An interactive, self-serve analytics workspace for Talent Acquisition teams — built to replace static hiring reports with a live, explorable dashboard.

**🔗 Live Demo:** https://project-dashboard-demo.netlify.app/hr-analytics-dashboard

> 💻 **Best viewed on a laptop/desktop** — this dashboard is not optimized for mobile screens, so please use a computer for the best experience.

> This is a public demo running on sample data. Data export is disabled in this preview — get in touch below if you'd like to see the full working version.

---

## Overview

Recruitment teams typically track hiring funnel health across scattered spreadsheets — open positions, time-to-fill, source effectiveness, recruiter load — updated manually and shared as static reports. This dashboard turns that into a single, live workspace: upload your data once and explore it interactively, without waiting on a data team for the next update.

## Features

- **Upload your own data** — drop in a CSV/Excel file of recruitment data, or explore with the built-in sample dataset
- **Auto-generated KPI cards** — open positions, time-to-fill, offer acceptance rate, source effectiveness, and more, calculated automatically from your data
- **Custom chart builder** — pick your own metrics and dimensions to build new visuals on the fly, without needing a BI tool
- **Dynamic filtering** — slice the entire dashboard by recruiter, department, source, or time period in real time
- **Built-in notes panel** — capture observations and action items directly on the dashboard for review meetings
- **Presentation mode** — a clean, distraction-free view for walking stakeholders through the numbers live
- **Light/dark theme toggle**

## Who It's For

- Talent Acquisition leads who need a self-serve view of hiring performance
- HR managers preparing for leadership reviews
- Recruiters who want to track their own funnel without building a report from scratch every week

## Privacy

All processing happens directly in your browser — nothing is uploaded to a server, making it safe to use with real recruitment data.
